# WebServer-Android

**The #1 offline web server APK by Topt Studio – under 0.5 MB.**

Turn any Android phone, tablet, or TV box into a full HTTP/HTTPS server.  
Zero‑config, no internet, no cloud, no sign‑ups.

## Features

- 📦 **Size:** APK < 0.5 MB
- 📤 **Resumable uploads:** 10 MB chunks, survives crashes
- 📥 **Folder as ZIP:** streaming download of entire folders
- 🎥 **4K video & hi‑res audio streaming**
- 🌐 **Static website hosting** (HTML/CSS/JS)
- 🔐 **Built‑in HTTPS** with one‑tap toggle
- 🔍 **mDNS discovery** (Bonjour/Zeroconf)
- 🛠️ **File management:** Delete, Rename, Create Folder, Upload
- 🌗 **Auto dark/light theme**
- 📡 **Works over Wi‑Fi, Hotspot, or Cellular – completely offline**

## Quick Start

1. Download the APK from [Releases](https://github.com/toptstudio/WebServer-Android/releases)
2. Install and grant storage & notification permissions
3. Choose a folder to share
4. Set the port (default `9999`)
5. Tap **Start Server**
6. On another device, open `http://<phone-ip>:9999`
